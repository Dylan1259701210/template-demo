## 🚀 快速开始

### 环境要求

| 软件 | 版本 |
|:----:|:----:|
| Node.js | 18.0+ |
| Docker | 20.0+ |
| PostgreSQL | 14.0+ |
| Redis | 6.0+ |

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/yourname/saas-platform.git

# 2. 安装依赖
npm install

# 3. 配置环境
cp .env.example .env

# 4. 启动服务
npm run dev
```

### 访问地址

| 服务 | 地址 |
|:----:|:----:|
| 前端 | http://localhost:3000 |
| 后端 | http://localhost:8000 |
| 数据库 | localhost:5432 |
